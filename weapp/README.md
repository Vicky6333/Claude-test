# 下钟计时器 · 微信小程序

输入上班时间和坐班时长，自动算出下班时间；可选按「月薪 ÷（本月工作天数 × 每天坐班时长）」计算日薪 / 时薪。苹果浅色风格，到点自动撒花 🎉。

## 目录结构

```
weapp/
├── app.js / app.json / app.wxss      # 小程序入口与全局配置
├── sitemap.json                       # 收录规则
├── project.config.json                # 开发者工具项目配置
└── pages/index/                       # 唯一页面
    ├── index.wxml                     # 结构
    ├── index.wxss                     # 样式
    ├── index.js                       # 逻辑
    └── index.json                     # 页面配置
```

## 本地预览（手机上看效果）

1. 下载安装 **微信开发者工具**：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 打开 → 「导入项目」→ 目录选择本 `weapp/` 文件夹
3. AppID：
   - 想直接预览：选 **「测试号」**（无需注册）即可在工具里跑、并用「预览」生成二维码到自己手机微信里看
   - 想正式发布给别人：填你自己注册的小程序 AppID（见下）

## 正式发布给别人用（让它能在微信里被搜索/转发打开）

> 这一步需要一次性注册，之后才能真正「在微信内直接打开」。

1. 到 https://mp.weixin.qq.com 注册一个**小程序账号**（个人主体即可，免费），实名认证
2. 在「开发管理 → 开发设置」拿到 **AppID**，填进 `project.config.json` 的 `appid`
3. 在开发者工具里点 **「上传」** → 到 mp 后台「版本管理」里**提交审核** → 审核通过后**发布**
4. 发布后即可在微信「搜索小程序」找到，或把小程序卡片**转发给好友/群**，对方点开就在微信内原生打开

## 说明

- 纯前端、无任何后端与网络请求，所有计算在本地完成。
- 工作天数默认按所选月份的工作日（周一~周五）自动计算，可手动改以扣除法定节假日 / 调休。
